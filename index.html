01 背景与目标

为什么做 AI 绘本

Dino AI 是一款面向 4-13 岁儿童的 AI 英语学习 App。当前内容矩阵包含系统课、复习课、单词 PK 游戏，但缺少一种低压力、高兴趣、可反复消费的阅读内容。

所有孩子读的是同一本书，同一个故事，同一个主角。
传统绘本的根本问题 —— 千人一面。

核心痛点

📋
内容同质化

所有孩子看到的绘本一样，无法匹配个体兴趣

⏳
产能瓶颈

人工创作一本周期 1-2 周，远低于消耗速度

😴
动力不足

"又是别人的故事"，缺乏代入感和主动阅读意愿

🎯
难度不匹配

固定绘本无法精准匹配当前词汇量和语言水平

核心假设

当绘本故事来自孩子自己的世界 —— 自己的宠物、喜欢的玩具、自己取的名字 —— 阅读完成率、重复阅读率、词汇留存率会显著高于通用绘本。

MVP 目标

「AI 为孩子生成个性化绘本」这种内容形态，孩子是否愿意读完、读完后是否愿意再来一本？

02 三种输入方式

AI 绘本可以怎么触发

核心假设是「孩子的世界变成故事」。基于不同的输入方式，我们设计了三条路径：

📸

上传图片 · 拍照变故事

拍下你最喜欢的玩具/宠物/房间，Dino 帮你变成绘本！

泰迪熊照片 → Teddy Bear's Space Adventure
家里的小猫 → Kitty's Day at School
自己的画 → 画中角色变绘本主角
代入感最强 拍照最直觉 需 Vision API
🎙️

语音输入 · 说出你的故事

长按说话告诉 Dino 你想看什么故事，AI 为你量身创作！

"我想看恐龙去太空" → Dino's Journey to Mars
"公主和龙的故事" → The Princess & Friendly Dragon
"I want animal stories" → 动物词汇绘本
自由度最高 低龄友好 支持中英文
🏷️

预设主题 · 一键选择

不知道想看什么？从 Dino 精选的主题里挑一个！

零门槛 → 点一下就开始生成
每次不同 → AI 在主题内随机创作
运营可控 → 按节日/热点推荐
4岁可用 零门槛 个性化弱

预设主题矩阵

🐱 动物世界 L1-L4 🚀 太空探索 L2-L4 🏰 童话故事 L1-L3 🌊 海底世界 L1-L3 👨‍👩‍👧 日常生活 L1-L2 🎄 节日故事 L2-L4 🏫 校园趣事 L2-L4 🦸 超级英雄 L3-L4

📌 MVP 策略：三种方式全做，引导顺序不同

• 新用户首次进入 → 先展示 预设主题（零门槛体验）

• 第 2 次进入 → 引导 语音输入（"这次想看什么故事？说给 Dino 听！"）

• 第 3 次及以后 → 引导 上传图片（"拍一张你喜欢的东西吧！"）

05 MVP 边界

先做什么，不做什么

✓ MVP 必做
  • 三种输入方式（图片 + 语音 + 主题）
  • AI 全链路（故事→插画→语音→组装）
  • 沉浸式阅读器（翻页+朗读+点词）
  • 渐进式等待（Dino 动画+逐页预览）
  • 我的书架（正在阅读+已读+收藏）
  • 阅读进度记录（退出续读）
  • 内容安全审核（文本+图像）
  • 用量控制（免费 1 本/天，VIP 3 本）
✗ MVP 不做
  • 绘本分享海报
  • 阅读排行榜
  • 课后练习题
  • 插画风格自选（V2）
  • 绘本评论 / 评分
  • 家长端阅读报告
  • 混合推荐算法
  • App 内嵌（先 Web）

🎨

AI / 算法团队

Prompt 体系 + 质量标准

AI 绘本的核心体验取决于「故事写得好不好」和「插画画得好不好」。Prompt 体系不对齐，输出质量不可控。

  • A1故事 Prompt 如何按 Level 分层？L1 和 L4 的句式、词汇、篇幅差异如何体现？
  • A2插画如何保持同一绘本内角色一致性？是否需要 IP Adapter / LoRA？
  • A3图片上传后识别精度如何保证？GPT-4o Vision 还是自建？
  • A4插画中可能出现拼写错误的英文字母？如何检测过滤？
  • A58 页并行生成的 API 并发限制和成本控制方案？
📄 产出物：故事 Prompt 模板 + 插画 Prompt 模板 + 质量评估标准
🛡️

安全合规

儿童内容安全审核规则和流程

儿童产品，内容安全零容忍。AI 生成的文本和图片必须在用户看到之前完成审核。

  • S1用户上传图片的安全审核方案？（自建 vs 第三方 vs 混合）
  • S2AI 生成文本除 NSFW 外是否有教育相关禁词表？
  • S3AI 生成图片是否需要人工抽检？比例和 SLA？
  • S4审核不通过时是否区分"素材不合适"和"结果不合适"？
📄 产出物：审核清单 + 自动审核方案 + 人工抽检流程
⚙️
